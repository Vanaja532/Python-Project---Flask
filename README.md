# Expense Tracker Dashboard

A simple web-based **Expense Tracker Dashboard** designed to help users record, manage, filter, and visualise their spending.

## Features

* Add expenses with description, amount, date, and category
* Edit and delete existing expenses
* Filter expenses by date range and category
* Automatically calculate total spending
* Export filtered expense data to CSV
* View spending by category using a pie chart
* View spending trends over time using a bar chart
* Clean and responsive dashboard interface

## Dashboard

The dashboard provides a central view of expense records, totals, filters, and visual spending analytics.

## Example Categories

* Food
* Transport
* Other

## Purpose

This project demonstrates the development of a practical **CRUD-based web application** with data filtering, calculations, CSV export, and interactive data visualisation.
